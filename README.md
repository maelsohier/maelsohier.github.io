## Fonctionnalités Principales

- **Architecture One-Page dynamique** : Navigation fluide avec un menu latéral ancré.
- **UI/UX Dark Mode "Cyber"** : Design moderne avec des effets de néon et un arrière-plan orienté data/tech.
- **Caméléon Script (Intersection Observer)** : Le thème de couleur principal (`--primary`) du site s'adapte automatiquement et de manière fluide en fonction de la section visible à l'écran.
- **Filtrage de projets** : Système de tri asynchrone en JavaScript Vanilla pour filtrer les projets par catégorie (Réseaux, Sécurité, Développement).
- **Profil International** : Section dédiée pour mettre en avant mes compétences en anglais (Vidéo d'intégration et CV au format PDF).
- **Responsive Design** : Interface entièrement adaptable (Mobile, Tablette, Desktop).

## Technologies Utilisées

- **HTML5** : Sémantique et structure.
- **CSS3** : Variables CSS (`oklch`), Flexbox, CSS Grid, Transitions avancées et Media Queries.
- **JavaScript (Vanilla)** : Manipulation du DOM, écouteurs d'événements et API Intersection Observer pour les effets au scroll.
- **FontAwesome (v6)** : Bibliothèque d'icônes vectorielles.
- **Google Fonts** : Polices d'écriture *Orbitron* (Titres) et *Corptic* (Sous-titres).
